# CS 5v5 隐私政策模板

> 当前为模板，正式上线前需要替换为真实发布主体、联系方式、SDK 清单和数据处理说明。

## 当前版本数据处理

当前版本未接入真实广告、内购、统计、登录或崩溃上报 SDK。游戏数据主要保存在本机：

- 星星数量
- 已解锁地图
- 累计击杀/死亡
- 设置项：音量、灵敏度、画质、选中地图、AI 难度
- 每日奖励日期
- 每日任务日期、进度和领取状态
- 教程完成状态

这些数据保存在 Godot `user://` 目录，不会由游戏主动上传。

## 未来接入 SDK 时必须补充

如果后续接入广告、内购、统计或崩溃上报，需要在此补充：

- SDK 名称、服务提供方、用途。
- 收集的数据类型，例如设备标识符、广告标识符、购买记录、崩溃日志、性能数据。
- 是否用于追踪或个性化广告。
- 数据共享对象和退出方式。
- 用户删除数据或联系开发者的方式。
