# CS 5v5 商业化方案

## 当前原则

- 当前版本不接入真实广告或内购 SDK，只提供 `MonetizationService` 抽象。
- 核心玩法不能依赖广告成功；广告不可用时玩家仍可通过比赛、每日奖励和每日任务获得星星。
- 本地星星容易被篡改，不适合作为真实高价值付费权益；真实付费权益需要平台收据校验或服务端校验。

## MVP 变现路径

1. 免费下载。
2. 激励广告：
   - 星星不足时看广告获得少量星星。
   - 胜利后看广告翻倍星星。
   - 战败后看广告获得补偿星星。
3. 内购：
   - 去广告。
   - 星星包。
   - 后续可扩展皮肤或武器外观。

## 星星经济建议

- 每日奖励：2 星。
- 每日任务：今日击杀 3 人 +1 星、赢得 1 局 +2 星、战斗获得 2 星 +1 星。
- 胜利：1 星。
- MVP 胜利：2 星。
- 激励广告：建议 3 星。
- 地图解锁：前 3 张免费，后续递增为 `6/10/10/12/12/15/15/18` 星。
- 递增表：废弃工厂 6、丛林营地 10、古城遗迹 10、海港码头 12、霓虹都市 12、地下洞穴 15、太空站 15、火山熔岩 18。
