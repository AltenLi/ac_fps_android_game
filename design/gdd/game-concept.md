# CS 5v5 — 游戏概念文档

## 1. Overview（概述）

CS 5v5 是一款低模 3D 第一人称单人枪战游戏，使用 Godot 4.6 开发。玩家加入蓝队（玩家 + 4 名队友 AI），对战 5 名橙队 AI。每局 300 秒，一方全灭可提前结算，时间到按存活人数判胜，人数相同为平局。

当前版本定位为可玩预发布原型：玩法、地图、星星解锁、每日奖励、每日任务、首局教程、触屏控制和基础留存已具备；真实广告、内购、统计、崩溃上报和商店发布材料仍需后续接入。

## 2. Player Fantasy（玩家体验目标）

玩家应该感受到：

- 低门槛进入 5v5 枪战的紧张感。
- 与 AI 队友协作、消灭最后一名敌人时的成就感。
- 三把武器差异带来的节奏变化：M416 连发、巴雷特高伤、RPG 爆炸。
- 星星解锁地图和每日任务带来的局外成长。
- 在手机上也能用虚拟摇杆和右侧按钮顺畅游玩。

## 3. Detailed Rules（详细规则）

### 比赛规则

- 蓝队：玩家 + 4 名队友 AI。
- 橙队：5 名敌方 AI。
- 回合时长：300 秒。
- 胜负条件：
  - 任意一方全部阵亡，另一方获胜。
  - 时间到，存活人数多的一方获胜。
  - 时间到且双方存活人数相同，判定平局。

### 玩家生命与死亡

- 玩家：100 HP + 30 护盾。
- AI：100 HP。
- 死亡后不复活，可观战蓝队队友并选择下一局或返回首页。

### 武器

| 武器 | 类型 | 定位 |
| --- | --- | --- |
| M416 | 射线 | 18 伤害 / 0.11s 冷却，高射速、中等伤害、主战武器 |
| 巴雷特 | 射线 | 105 伤害 / 1.45s 冷却，高伤害、低射速、远距离点杀 |
| RPG | 投射物 | 95 伤害 / 5.0 爆炸半径 / 2.6s 装弹，慢速火箭弹、范围爆炸伤害 |

AI 交战距离按武器区分：M416 45，巴雷特 85，RPG 50，未知武器回退 32。

### 地图

当前 11 张地图由 `scripts/map_registry.gd` 统一注册：城市巷战、沙漠要塞、雪原基地、废弃工厂、丛林营地、古城遗迹、海港码头、霓虹都市、地下洞穴、太空站、火山熔岩。

前三张地图免费，其余地图按递增成本解锁：废弃工厂 6 星，丛林营地 10 星，古城遗迹 10 星，海港码头 12 星，霓虹都市 12 星，地下洞穴 15 星，太空站 15 星，火山熔岩 18 星。地图资源为原创低模程序化几何体，不复制受版权保护布局或素材。

### 进度与奖励

- 胜利获得 1 颗星。
- 玩家为 MVP 时获得 2 颗星。
- 每日奖励可领取 2 颗星。
- 每日任务每日重置：今日击杀 3 人奖励 1 星，赢得 1 局奖励 2 星，战斗获得 2 星奖励 1 星。
- 星星用于解锁地图；当前为本地软货币，不代表真实付费权益。
- 首次进入首页且教程未完成时自动弹出分步骤教程，完成或跳过后保存教程完成状态。

### 商业化边界

当前版本只有 `MonetizationService` 抽象和调试占位。正式接入广告/内购前，必须完成 SDK 接入、隐私政策、用户协议、数据安全声明和商店审核材料。

## 4. Formulas（公式）

### 伤害计算

```text
直接伤害 = weapon_config.damage
RPG 爆炸伤害 = weapon_config.damage × clamp(1 - distance / splash_radius, 0.25, 1.0)
```

### 胜负判定

```text
蓝队存活数 = count(combatants where team="blue" and health.is_alive=true)
橙队存活数 = count(combatants where team="orange" and health.is_alive=true)

if 橙队存活数 == 0: 蓝队胜
if 蓝队存活数 == 0: 橙队胜
if remaining_time <= 0:
	if 蓝队存活数 > 橙队存活数: 蓝队胜
	if 橙队存活数 > 蓝队存活数: 橙队胜
	else: 平局
```

### 地图解锁

```text
if map.cost == 0: 已解锁
else if map.id in PlayerData.purchased_maps: 已解锁
else if total_stars >= map.cost: 可消耗星星解锁
```

## 5. Edge Cases（边界情况）

- 存档中出现非法地图 ID：加载时过滤。
- 设置中出现非法地图或难度：回退默认值。
- 地图场景加载失败：回退城市巷战，避免崩溃。
- 星星不足：不解锁地图，可通过比赛、每日奖励或每日任务获得星星。
- 未接入广告 SDK：商业化奖励入口显示不可用，不阻塞核心玩法。

## 6. Dependencies（依赖系统）

- **MatchManager**：动态加载 MapRegistry 地图，组织 PlayerController、AIController、HUD、MobileControls。
- **MapRegistry**：地图元数据唯一来源。
- **PlayerData**：星星、地图解锁、战绩、每日奖励、每日任务、教程状态、去广告状态。
- **MonetizationService**：广告/内购抽象，占位实现不绑定具体 SDK。
- **GameSettings**：音量、灵敏度、画质、选中地图、AI 难度。
- **WeaponSystem**：WeaponConfig、Projectile、伤害与弹药。
